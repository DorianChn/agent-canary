# agent-canary 赞助收款网关

单文件自托管收款服务：**微信支付（Native 扫码，API v3）+ 支付宝（当面付 precreate）**，用于把项目流量转化为资金（赞助 → 付费推广预算 / 服务器费用）。

- 零框架、零遥测，只依赖 `qrcode` 一个包
- 微信回调：平台证书验签（RSA-SHA256）+ AES-256-GCM 资源解密，验不过直接 401
- 支付宝异步通知：RSA2 验签，验不过直接 401
- 金额服务端校验（1–10000 元），前端不决定价格
- 订单本地持久化在 `orders.json`（记得把它加进备份，不要提交进 git）

## 个人版 Personal（$10/月）

- 定价：**US$10/月**，微信/支付宝按人民币收取，默认 ¥72/月（`.env` 里 `PERSONAL_USD` / `PERSONAL_CNY` 可改）
- 绑定标识：GitHub 用户名或邮箱，下单时必填；订阅状态唯一查询入口：
  `GET /api/subscription/:handle` → `{"active":true,"expiresAt":"…"}`
- 计费模型：微信/支付宝没有面向个人的自动代扣，所以一期 = 30 天；**到期后再付一次，从当前到期日起顺延 30 天（可叠加）**，中途续订不亏
- 支付成功回调后自动写 `subscribers.json` 并延长有效期；权益核对以该文件 / API 为准
- 页面内置订阅状态自查（输入 handle 即显示是否生效、何时到期）

## 零成本方案：个人收款码 + 人工确认【0 元，当天可用】

把你的个人收款码图片放进 `sponsor/qr/`（命名 `wechat.png` / `alipay.png`），重启即生效——页面自动多出一个"扫码个人收款码"卡片：付款人转账（备注 GitHub 用户名）后提交登记，你在账单里看到钱到账，一条命令开通：

```bash
node grant.mjs pending          # 列出待确认登记
node grant.mjs list             # 列出订阅及到期时间
node grant.mjs grant <handle>   # 开通个人版 30 天（可加月数参数，自动叠加）
node grant.mjs revoke <handle>  # 撤销后续激活（已签发许可到期前仍有效）
```

- 费率 **0%**（个人收款码微信/支付宝都不收手续费），无需任何资质
- `qr/` 目录已 gitignore——收款码是个人信息，不要提交进仓库
- 缺点：不自动确认（需要你每天看一眼账单 + 跑一次命令）

## 零成本全自动：V免签部署指南【已内置支持，配安卓手机】

原理：付款扫你的个人收款码（自动加金额尾数防撞单）→ 安卓监控端 App 监听到到账通知推给服务端 → 服务端按金额匹配订单 → 回调本网关自动开通。**0 开户费、0 费率、全自动**。网关已按官方协议内置适配器，服务端跑起来后只需三行配置。

### 1. 部署服务端（szvone/vmqphp，PHP+MySQL）

- **有云服务器/宝塔**（最顺）：下载 [vmqphp](https://github.com/szvone/vmqphp) 源码 → 新建网站，运行目录设为 `public`、伪静态选 `thinkphp`、默认文档把 `index.html` 放第一行 → 改 `config/database.php` 数据库 → 导入根目录 `vmq.sql` → 默认后台账号密码 admin/admin（**立即改掉**）
- **没有服务器**（本机跑）：装 [phpstudy](https://www.xp.cn)（自带 PHP+MySQL，建站步骤同上）+ [cloudflared](https://developers.cloudflare.com/cloudflare-one/connections/connect-networks/) 隧道把本机端口映射成公网 HTTPS 域名（vmq 域名和网关的 `PUBLIC_BASE_URL` 都必须是公网可访问的）
- 后台「系统设置」：上传你的个人收款码（微信/支付宝二维码管理里按价格档配置，或设置通用收款码链接），记下**通讯密钥**
- 后台「监控端设置」：拿到监控端配置信息

### 2. 配置安卓监控端

1. 从 [szvone/VmqApk](https://github.com/szvone/VmqApk) 下载 APK 装到你的安卓手机
2. 打开 App → 手动配置/扫码配置服务端地址和后台账号密码 → 登录
3. 开启服务：App 内点击"开启服务" → 跳转授予**无障碍/通知监听权限** → 回到 App 点"检测监听权限"确认正常
4. 手机设置三件套：V免签App、微信、支付宝都加入**电池优化白名单/自启动**；微信里关注「微信支付」和「微信收款助手」两个公众号（通知监听依赖它们）
5. 留插电常驻在线——它就是你的"到账探测器"

### 3. 网关配置（两行）

```env
VMQ_URL=https://你的vmq域名
VMQ_KEY=后台系统设置里的通讯密钥
```

重启网关即生效。下单 → 支付页（自动加金额尾数）→ 手机收到款 → 监控端推送 → 验签回调 → 订阅自动开通，全程无人工。已按官方协议端到端验证（签名下单/回调验签/伪造拒绝）。

### 4. 注意

- 微信/支付宝**个人收款码高频收款有被风控的可能**（限额/封码），金额小、频率低的赞助场景一般没事，但别把它当商用收款用
- vmq 订单有有效期（后台可设，默认 5 分钟），付款人超时未付需重新下单
- V免签监控端与部分手机系统不兼容（ readme 承认），遇到监听异常换手机或用模拟器挂机

## 个人免商户最快路径：易支付(Epay)协议聚合平台【已内置支持】

不想办执照？网关内置了"易支付"通用协议适配器——国内个人免签聚合平台（ZPAY、七相PAY 等）都用这套协议，**填三行配置即可收款**：

```env
EPAY_API_URL=https://平台域名
EPAY_PID=你的商户PID
EPAY_KEY=你的商户密钥
```

- 支持微信 + 支付宝，个人实名即可开通（手机号注册 → 实名 → 付一次性开户费 88~148 元 → 后台拿 PID/密钥）
- 平台费率约 1%~2% + 官方 0.6%，比自建商户略贵，但当天可用
- 个人版订阅（$10/月）照常工作：回调验签通过 → `subscribers.json` 自动顺延

**平台现状提醒（2026-09 核实）**：
- 虎皮椒（xunhupay）：2025-11 起主通道注册临时关闭（微信跳转支付同步暂停），PC 扫码不受影响，暂不建议新注册
- 候选：ZPAY（z-pay.cn，开户 88/288 元）、七相PAY（qixiangpay.cn，开户 148 元，费率 1.2%+0.6%）
- ⚠️ 此类平台有规模小、跑路风险，建议：开户前在官网确认通道可用；账户余额及时提现；先小额试跑一周再放开订阅

## 爱发电（零代码兜底）

连服务器都不想部署：[爱发电](https://afdian.net)个人实名即可开通，自带微信/支付宝收款和订阅档位（抽成约 8%）。缺点是无法自动管理我们网关里的订阅权益，适合作为前期链接兜底。

## 快速体验（无需任何商户资质）

```bash
cd sponsor
npm install
npm start          # DEMO 模式自动生效
```

打开 http://localhost:8787 → 选金额（或订阅个人版）→ 生成二维码 → 手机扫码会打开**模拟支付页**（不扣款）→ 点确认 → 赞助页 2 秒内变"支付成功"，个人版会显示生效日期。整条链路（下单 → 二维码 → 轮询 → 回调 → 订单/订阅完成）与真实模式完全同构。

## 配置真实收款

生产环境必须确认 `DEMO=0`，并配置至少一种真实支付方式、人工收款码或
V免签/Epay。否则网关会运行在演示模式；演示支付只适合本机联调，远程
`/api/activate` 不会为公网请求签发许可。

```bash
cp .env.example .env   # 填入下面的凭据，DEMO=1 删掉
```

### 微信支付（Native 扫码）

1. 注册商户号：[pay.weixin.qq.com](https://pay.weixin.qq.com)（需营业执照或个体户；小微商户也可）
2. 商户平台 → 「账户中心 → API 安全」：
   - 申请 **API 证书**，下载得到 `apiclient_key.pem`（私钥）和证书序列号
   - 设置 **APIv3 密钥**（32 位字符串，自己设并保存）
3. 「产品中心」开通 **Native 支付**
4. 填 `.env`：`WECHAT_MCHID` / `WECHAT_SERIAL` / `WECHAT_APPID`（公众号或开放平台 appid）/ `WECHAT_APIV3_KEY` / `WECHAT_PRIVATE_KEY_PATH=./apiclient_key.pem`

### 支付宝（当面付）

1. [open.alipay.com](https://open.alipay.com) 创建网页/移动应用，获取 `APPID`
2. 「应用信息 → 接口加签方式」选**公钥模式**：用支付宝密钥生成工具（或 openssl）生成 RSA2 密钥对 → 上传**应用公钥**，平台返回**支付宝公钥**
3. 签约「**当面付**」产品（需要企业/个体户资质；个人开发者建议先用下面的零代码方案）
4. 填 `.env`：`ALIPAY_APP_ID` / `ALIPAY_PRIVATE_KEY_PATH`（应用私钥 PEM）/ `ALIPAY_PUBLIC_KEY_PATH`（支付宝公钥，纯 base64 也行）

### 上线要求

- `PUBLIC_BASE_URL` 必须是**公网 HTTPS** 地址（微信/支付宝的异步回调会打到它）
- 最省事的部署：任意 VPS + Caddy（`pay.你的域名.com { reverse_proxy localhost:8787 }` 两行配置自动签证书）
- 本地联调可临时用 `cloudflared tunnel --url localhost:8787`
